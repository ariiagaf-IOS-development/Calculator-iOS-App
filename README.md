## Features

- Basic arithmetic operations
- Decimal input
- Percentage conversion
- Sign toggle (`+/-`)
- All Clear (`AC`)
- Portrait and landscape layout

## Tech Stack

- Swift
- UIKit
- Storyboard
- Xcode
- MVC

## Project Structure

```bash
Calculator
├── Controller
│   └── ViewController.swift
├── Model
│   └── CalculatorLogic.swift
├── View
│   ├── Main.storyboard
│   ├── Assets.xcassets
│   └── LaunchScreen.storyboard
```

## What I Practiced

- Building layouts with `UIStackView`
- Handling button input and display updates
- Separating UI and calculation logic
- Organizing an iOS app with MVC

## Run the Project

1. Open the project in Xcode
2. Run it on an iPhone Simulator or a physical device
